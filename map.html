 Panduan WebGIS

      

        
1. Buka Layer
Klik tombol Atas untuk memilih kategori fasilitas: Kost, Rumah Makan, Laundry, Minimarket, ATM, Print/Fotokopi, Fasilitas Kesehatan, atau Emergency.

        
2. Pakai Filter
Klik Murah, 24 Jam, Dekat Kampus, atau Emergency. Filter ini membaca langsung isi kolom Excel seperti Harga, Jam Operasional, dan Buka 24 Jam.

        
3. Baca Detail
Klik marker di peta untuk melihat nama tempat, alamat, jam, harga, rating, kontak, dan link Google Maps.

        
4. Buka Rute
Di popup marker, klik Buka Rute. Sistem akan membuat rute dari Rektorat UPN ke lokasi tujuan.

        
5. Buka Insight
Klik tombol Insight. Panel insight akan tampil seperti layer/filter agar rapi dan mudah dibaca.

        
6. Update Data
Untuk memperbarui data, cukup ganti file Excel di folder data/ dengan nama file yang sama. Tidak perlu file JS data.
