 Panduan WebGIS

      

        
1. Buka Layer
Klik tombol Atas untuk memilih kategori fasilitas: Kost, Rumah Makan, Laundry, Minimarket, ATM, Print/Fotokopi, Fasilitas Kesehatan, atau Emergency.

        
2. Pakai Filter
Klik Murah, 24 Jam, Dekat Kampus, atau Emergency. Filter membaca langsung isi Excel di folder data/.

        
3. Baca Detail
Klik marker di peta untuk melihat nama tempat, alamat, jam, harga, rating, kontak, dan link Google Maps.

        
4. Buka Rute
Di popup marker, klik Buka Rute. Jika routing online gagal, peta tetap menampilkan garis lurus ke lokasi.

        
5. Buka Insight
Klik Insight. Panel Insight sekarang tampil seperti layer/filter agar rapi, bisa discroll, dan mudah dibaca.

        
6. Update Data
Untuk memperbarui data, cukup ganti file Excel dengan nama yang sama di folder data/. Tidak perlu membuat file data JS.
